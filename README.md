# Arena — Android WebView wrapper

Официальный сайт Arena: https://arena.ai/

Приложение открывает Arena внутри WebView без адресной строки.
Включены JavaScript, DOM Storage, cookies, сторонние cookies и выбор файлов.

## Сборка
GitHub Actions автоматически собирает `app-debug.apk` при push в `main` или вручную через Actions → Build Arena APK → Run workflow.
